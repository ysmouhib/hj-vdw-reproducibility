# References and software

## CryptoMiniSat and SAT software

- Mate Soos, *CryptoMiniSat*, official repository: <https://github.com/msoos/cryptominisat>. The repository provides the `cryptominisat5` command-line program and C++/Python interfaces. The exact experiments documented here use `pycryptosat` 5.18.0.
- Mate Soos, Karsten Nohl, and Claude Castelluccia, *Extending SAT Solvers to Cryptographic Problems*, SAT 2009, Lecture Notes in Computer Science 5584, 244–257. This is the citation requested by the CryptoMiniSat project.
- Marijn J. H. Heule, *vdWaerden: computing lower bounds for van der Waerden numbers using SAT*: <https://github.com/marijnheule/vdWaerden>.
